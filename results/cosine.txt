direction] and w_behavior = logistic(same acts, BEHAVIOR labels = did the DEFAULT reply offer feedback?),
report cos(w_intent, w_behavior). Forward-pass-only, no long generation.

feedback-offering behavior axis. The deflationary reading ("the handle is a generic feedback-suppression knob
correlated with intent by construction") is REFUTED. The fork: cos~0.95 -> deflationary; cos~0.3 -> routing.
We got ~0.1, past routing. Reconciles with evalsteer (steering recognize suppresses REQUESTED feedback on Qwen):
steering changes the represented INTENT, which the model routes into behavior forcefully enough to override the
surface request -> intent-routing, and a powerful one, not a feedback knob. The ~30-37% label disagreement (the
discard events) is what allows the two axes to be orthogonal. => last-round hedges were overcautious; replace
with the positive control.
